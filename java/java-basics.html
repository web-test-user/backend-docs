Spring Boot Controller Veri Yakalama

İstek Verilerini Yakalama (Annotations)

Spring Boot'ta Controller metodlarına istemciden (client) gelen veriyi yakalamak ve işlemek için kullanılan en yaygın annotation'lar şunlardır:

  • @PathVariable

    URI (istek adresi) içerisindeki değişken değerleri yakalamak için kullanılır. RESTful API tasarımlarında kaynak belirtmek amacıyla sıkça tercih edilir.

    java 
    @GetMapping("/api/users/{id}")
public ResponseEntity<User> getUserById(@PathVariable("id") Long userId) {
    // URL: http://localhost:8080/api/users/42
    // userId degeri otomatik olarak 42 olacaktir.
    return ResponseEntity.ok(userService.findById(userId));
}
  • @RequestBody

    Gelen HTTP istek gövdesindeki (Request Body) veriyi (genellikle JSON veya XML) Java nesnesine (DTO/Entity) otomatik olarak dönüştürür. POST, PUT gibi veri gönderen isteklerde kullanılır.

    java 
    @PostMapping("/api/users")
public ResponseEntity<User> createUser(@RequestBody UserCreateDto userDto) {
    // Gelen JSON verisi otomatik olarak UserCreateDto nesnesine eşlenir.
    return ResponseEntity.status(HttpStatus.CREATED).body(userService.create(userDto));
}
  • @RequestParam

    Query (sorgu) parametrelerini veya HTML form verilerini yakalamak için kullanılır. Parametrelerin opsiyonel olması veya varsayılan değer alması sağlanabilir.

    java 
    @GetMapping("/api/users")
public ResponseEntity<List<User>> getUsers(
        @RequestParam(value = "role", required = false, defaultValue = "USER") String role,
        @RequestParam(value = "page", defaultValue = "0") int page) {
    // URL: http://localhost:8080/api/users?role=ADMIN&page=2
    return ResponseEntity.ok(userService.findAllByRole(role, page));
}
  • @RequestHeader

    HTTP istek başlıklarındaki (Request Headers) meta verileri veya özel parametreleri (örn: Authorization token) yakalamak için kullanılır.

    java 
    @GetMapping("/api/secure/data")
public ResponseEntity<String> getSecureData(@RequestHeader("Authorization") String token) {
    // HTTP Header icindeki "Authorization" anahtarinin degeri token degiskenine aktarilir.
    return ResponseEntity.ok(securityService.processToken(token));
}
  • @RequestPart

    Multipart isteklerinde (`multipart/form-data`) dosya yükleme işlemlerini ve karmaşık nesneleri birlikte göndermek için kullanılır. Özellikle bir dosya (resim, pdf vb.) ile beraber JSON metadata göndermek için idealdir.

    java 
    @PostMapping(value = "/api/profile", consumes = MediaType.MULTIPART_FORM_DATA_VALUE)
public ResponseEntity<String> updateProfile(
        @RequestPart("image") MultipartFile file,
        @RequestPart("metadata") UserProfileDto dto) {
    // Hem yuklenen dosyayi (MultipartFile) hem de JSON nesnesini (UserProfileDto) yakalar.
    return ResponseEntity.ok(profileService.save(file, dto));
}
  • @ModelAttribute

    HTTP istek parametrelerini (form verileri veya query parametreleri) doğrudan bir Java nesnesine (Model nesnesine) bind (bağlama) etmek için kullanılır. Özellikle çok sayıda arama filtresi içeren GET isteklerinde veya klasik MVC formlarında tercih edilir.

    java 
    @GetMapping("/api/users/search")
public ResponseEntity<List<User>> searchUsers(@ModelAttribute UserSearchFilter filter) {
    // URL: http://localhost:8080/api/users/search?name=Ahmet&age=25&city=Istanbul
    // Query parametreleri filtre nesnesinin degiskenleriyle otomatik eslesir.
    return ResponseEntity.ok(userService.search(filter));
}
